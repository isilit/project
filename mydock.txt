Журнал посещаемости с биометрией
================================

Требования: Node.js 18+, Python 3.10+, веб-камера (для биометрии).

Установка (один раз)
--------------------
  cd project
  npm install
  cd backend
  pip install -r requirements.txt
  cd ..

Запуск через Electron (рекомендуется)
-------------------------------------
  npm run electron:dev

Поднимаются API (:5000), React (:3000) и окно Electron.
Биометрия работает только в Electron.

Запуск в браузере
-----------------
  Терминал 1:  npm run api
  Терминал 2:  npm start
  Открыть:     http://localhost:3000

Вход администратора
-------------------
  Логин:  adminAcademy
  Пароль: adminAcademy
  Админка: кнопка «Админка» в шапке или /admin

Пароли
------
Перед отправкой на сервер хешируются SHA-256 (в БД хранится хеш).
Старые аккаунты с Base64 нужно перерегистрировать или сбросить backend/database.db.

Пути
----
Все пути относительные к папке project — проект переносится на любой диск/ПК.
При необходимости: PYTHON=python, PORT=5000, REACT_APP_API_URL=http://127.0.0.1:5000

Структура
---------
  backend/   — API и main_logic.py
  photo/     — фото с камеры
  admin/     — описание админ-модуля
  electron/  — оболочка Electron
