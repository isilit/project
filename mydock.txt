Журнал посещаемости с биометрией — запуск через Electron
=========================================================

Требования
----------
- Node.js 18+
- Python 3.10+ с установленными зависимостями биометрии
- Веб-камера (для идентификации и регистрации лица)

1. Установка зависимостей (один раз)
------------------------------------
Откройте терминал в папке project:

  npm install
  npm install --save-dev electron concurrently wait-on cross-env
  npm install better-sqlite3

  cd backend
  pip install -r requirements.txt
  cd ..

2. Запуск в режиме разработки
-----------------------------
В папке project выполните:

  npm run electron:dev

Скрипт:
- поднимает Flask API на http://127.0.0.1:5000 (backend/server.py)
- запускает React на http://localhost:3000
- открывает окно Electron

3. Запуск только веб-версии (без Electron)
--------------------------------------------
Терминал 1 — API:
  cd backend
  python server.py

Терминал 2 — фронт:
  npm start

Откройте http://localhost:3000

4. Биометрия
------------
- На главной странице блок «Биометрическая идентификация».
- «Пройти биометрию» — захват лица, фото сохраняется в project/photo.
- «Идентификация» — запускает main_logic.py как дочерний процесс (в Electron).

5. Пароли
---------
При регистрации пароль кодируется в Base64 перед отправкой на сервер.

6. Локальная сессия
-------------------
В Electron логин/пароль и данные пользователя хранятся в SQLite
(файл session.db в каталоге данных приложения).

7. Сборка production
--------------------
  npm run build
  npm run electron

Переменные окружения (по желанию):
  PYTHON=python
  PORT=5000
