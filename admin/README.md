# Папка admin

Модуль администрирования журнала посещаемости.

## Доступ

- URL в приложении: `/admin`
- Только пользователи с `isAdmin = 1` или группой `Администрация`
- Учётная запись по умолчанию (если БД пуста):
  - логин: `adminAcademy`
  - пароль: `adminAcademy` (на сервер отправляется SHA-256)

## Возможности

- **Accounts** — просмотр и редактирование всех полей аккаунтов
- **Groups** — создание, переименование, удаление групп; список студентов в группе
- **persons / faces** — просмотр таблиц биометрии

## API (требуется заголовок `X-User-Id` администратора)

- `GET /admin/data`
- `PUT /admin/accounts/:id`
- `DELETE /admin/accounts/:id`
- `POST /admin/groups`
- `PUT /admin/groups/:id`
- `DELETE /admin/groups/:id`

Все пути в проекте относительные — перенос на другой компьютер без правки путей.
